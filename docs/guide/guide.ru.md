Debian Workstation превращает чистый Debian 13 в быстрый и тихий рабочий стол:
оконный менеджер i3 на X11, одна тёмная тема и один шрифт, всё настраивает
один скрипт. Это руководство проведёт от пустого диска до повседневной работы.

# Что понадобится

- компьютер amd64: ноутбук, настольный ПК или виртуальная машина;
- образ Debian 13 *netinst* на флешке;
- интернет во время установки.

# 1. Установите Debian

Ставьте Debian как обычно, но с двумя важными моментами:

- **Выбор программ:** оставьте отмеченными только *стандартные системные
  утилиты*. Окружение рабочего стола не нужно: у Workstation оно своё.
- **Пароль root:** оставьте пустым. Тогда ваш пользователь сразу получит `sudo`.

Если пароль root всё-таки задан, выдайте пользователю `sudo`, затем выйдите и
войдите снова:

```bash
su -
apt install sudo
usermod -aG sudo ВАШ_ПОЛЬЗОВАТЕЛЬ
```

# 2. Запустите установщик

Войдите в текстовую консоль под своим пользователем и выполните:

```bash
sudo apt install git
git clone https://github.com/vrubovoy/debian-workstation.git
cd debian-workstation
./install.sh
```

Папку `debian-workstation` не перемещайте и не удаляйте: ваши настройки ссылаются
на неё.

Установщик спросит пароль и какое-то время поработает сам. В конце он задаст
несколько вопросов. **Enter** выбирает предложенный ответ:

| Вопрос | Что это значит |
|---|---|
| Имя и почта для Git | Подпись в коммитах. Пропустите, если не пользуетесь Git. |
| Подписывать коммиты GPG | По желанию; обычно отвечают «нет». |
| Ключ SSH | Ключ для GitHub и серверов. |
| Драйвер NVIDIA | Спрашивается только при видеокарте NVIDIA. |
| Yazi, Neovim, VSCodium и др. | Программы от их разработчиков. Yazi и Neovim советуем поставить. |
| Расширения Firefox и VSCodium | Выберите нужные по одному. |
| Перезагрузить сейчас | Да, чтобы запустить рабочий стол. |

`./install.sh` можно запускать снова в любой момент: сделанное он пропускает.

# 3. Первый вход

После перезагрузки появится экран входа. Введите пароль и нажмите **Enter**.

- **Wi-Fi:** значок сети справа внизу или команда `nmtui` в терминале.
- **Раскладка:** `Alt+Space` переключает английскую и русскую.
- **Всё остальное** запускается клавишами ниже. `Super` — клавиша Windows.

# 4. Главные клавиши

| Клавиши | Действие |
|---|---|
| `Super+Enter` | Терминал |
| `Super+Space` | Найти и запустить программу |
| `Super+W` / `Super+E` / `Super+C` | Firefox / файловый менеджер / VSCodium |
| `Super+Q` | Закрыть окно |
| `Super+F` | Во весь экран |
| `Super+1` … `Super+0` | Перейти на рабочий стол 1–10 |
| `Super+Alt+1` … `Super+Alt+0` | Перенести окно на рабочий стол |
| `Super+стрелки` | Переход между окнами |
| `Super+Ctrl+стрелки` | Передвинуть окно |
| `Super+T` | Сделать окно плавающим и обратно |
| `Super+V` | История буфера обмена |
| `Print` / `Shift+Print` | Снимок экрана / области |
| `Super+L` | Заблокировать экран |
| `Super+Backspace` | Выключить, перезагрузить, усыпить, заблокировать, выйти |

Клавиши громкости и яркости работают как подписано. Если их нет:
`Super+F11` / `Super+F12` — громкость, `Super+F10` — выключить звук,
`Super+F1` / `Super+F2` — яркость.

Окна открываются рядом и занимают весь экран. Вместо сворачивания пользуйтесь
рабочими столами: один для браузера, другой для работы, третий для общения.

# 5. Терминал и файлы

В терминале работает оболочка Fish. Несколько команд экономят много времени:

| Команда | Что делает |
|---|---|
| `y` | Открыть файловый менеджер Yazi; `q` выходит в папку, где вы остановились |
| `z ИМЯ` | Перейти в папку, где вы уже бывали |
| `ffe` | Найти файл по имени и открыть его |
| `ffec ТЕКСТ` | Найти текст в файлах и открыть найденное |
| `hello` | Показать сведения о системе |

В терминале `Ctrl+C` копирует выделенный текст, а `Ctrl+V` вставляет его в
командную строку. Снимки экрана сохраняются в `~/Pictures/Screenshots` и сразу
попадают в буфер обмена.

# 6. Сон и питание

- Через 10 минут без действий экран блокируется.
- Через 15 минут экран гаснет и компьютер засыпает, если не играет музыка или
  видео.
- Чтобы разбудить, пошевелите мышью или нажмите клавишу, затем введите пароль.

# 7. Обновления

Обновления Debian ставятся как обычно:

```bash
sudo apt update
sudo apt full-upgrade
```

Чтобы получить новую версию Workstation:

```bash
cd ~/debian-workstation
git pull
./install.sh
```

Эта же команда обновляет и выбранные вами дополнительные программы.

# 8. Если что-то пошло не так

- **Нет сети после первой перезагрузки:** подключитесь заново через значок
  сети или `nmtui`. Wi-Fi, настроенный при установке Debian, не сохраняется.
- **Какая-то настройка выглядит не так:** запустите `./install.sh` ещё раз.
  Заменённые файлы лежат рядом с окончанием `.debian-workstation.bak`.
- **Всё остальное:** смотрите `docs/TROUBLESHOOTING.md` в репозитории или
  создайте issue на GitHub.
